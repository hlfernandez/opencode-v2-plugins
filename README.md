# OpenCode V2 Plugins

A personal collection of plugins for the [OpenCode](https://opencode.ai) V2 CLI.

## Plugins

| Plugin | Description |
| --- | --- |
| [git-panel](./git-panel) | Git section in the sidebar: latest commit plus the modified and new files waiting to be committed. |

Each plugin has its own README with install and configuration details.
